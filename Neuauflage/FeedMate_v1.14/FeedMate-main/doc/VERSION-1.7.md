# FeedMate v1.7

- Mehrere Automaten pro Fütterungszeit auswählbar
- Eingeklappte Karten mit Zeit, Automaten, Portion und Futter als Kurzansicht
- Vollständige Konfiguration nach dem Aufklappen
- Umgebrochene Smartphone-Navigation ohne horizontale Scrollleiste
- Demo wird direkt aus derselben Oberfläche wie die Firmware erzeugt

Beim Speichern wird ein Eintrag für jeden ausgewählten Automaten verteilt. Die Begrenzung von 32 Zeiten pro Automat aus v1.6 bleibt bestehen.
