Einstellungen

🎯 Motor-Kalibrierung

Kalibriere, wie lange der Motor drehen muss, um genau eine Portion Futter auszugeben.

Kalibrierungs-Assistent

  1. Stelle eine leere Schüssel unter den Automaten
  2. Klicke auf "Motor starten" und zähle, wie lange er läuft
  3. Wiege das ausgegebene Futter
  4. Gib die gemessene Zeit und das Gewicht ein
  5. Das System berechnet automatisch die Zeit pro Gramm
Dieser Wert wird für alle Futterzeiten verwendet.
